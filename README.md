# Race Overlay für iRacing

**Racecraft by derMorpheuz**

Overlay für iRacing: Relative, Standings, Radar, Delta mit Zeitstrahl, Fuel-Rechner, Boxen-Knopf für Fast Repair,
Streckenkarte mit Sektorzeiten, Schadensanzeige, Wetter, Sprachausgabe als Spotter und vieles mehr.

## Download

Die neueste Version gibt es unter **[Releases](https://github.com/derMorpheuz/iRacingOverlay-Releases/releases/latest)**:
`iracing_overlay.exe` herunterladen und starten.

## Updates

Das Overlay sucht beim Start selbst nach neuen Versionen und installiert sie auf Wunsch.
Deine Einstellungen liegen in `%APPDATA%\RaceOverlay` und bleiben bei Updates erhalten.

Menü: **Strg + Alt + O**
